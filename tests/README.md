# 服务端手工回归检查

当前没有自动化测试源码。以下检查需要对应 Minecraft 版本的 Fabric 测试服务器和玩家客户端；构建不会自动执行。

- 启动服务器，确认模组加载、配置与中英文消息正常。
- 使用两名玩家检查 `/tpa`、`/tpahere`、接受、拒绝、超时与移动取消。
- 检查 Home、Warp 的创建、改名、默认项、删除、GUI 和权限控制。
- 检查 `/spawn`、死亡后 `/back`、安全检查和传送延时。
- 检查 `/rtp` 的维度选择、并发请求、冷却与危险地形保护。
- 使用测试数据检查重启持久化、`/tpareload` 和 JSON 到 SQLite 导入。

请仅在测试服务器中操作；运行数据不提交到 Git。
